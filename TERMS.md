# Terms (the necessary parts)

You must own or be allowed to use this phone and this PC.

KUI Residuals looks at leftover app folders in three places on a phone you authorize (the folders you pick, or Shizuku if you already use it). Root is not required. Nothing is uploaded.

Set aside moves a leftover out of the way. Save a copy keeps a duplicate. Edit changes a leftover file you opened. Delete forever only works on folders already set aside, after you confirm twice. Hidden leftover names count only if the app is gone. If it is not an app leftover, we leave it.

KUI Desk is this computer and the phones you plug in. It can do the same leftover work on each authorized phone. It does not upload anything.
